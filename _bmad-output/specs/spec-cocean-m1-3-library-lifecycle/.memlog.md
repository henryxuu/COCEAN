topic: COCEAN M1.3 唱片生命周期与安全删除
updated: 2026-08-15T09:30
---

- (direction) COCEAN 当前仍以唱片库管理为优先；M1.3 不引入找歌、Still、下载 Lab 或大模型依赖。
- (decision) M1.3 定义为唱片生命周期与安全删除，补齐 M1.2a–M1.2d 之后的隐藏、隔离和恢复闭环。
- (constraint) WATCH_ONLY 根目录永远不得改名、移动、覆盖、删除或写入；扫描继续只读。
- (constraint) 只有部署时明确声明为 MANAGED 且以读写方式挂载的 Root 才允许隔离动作；现有 FNOS Music Root 不自动升级或改挂载。
- (capability) CAP-1：管理员可以持久隐藏或恢复一张 LibraryAlbum；列表与搜索默认排除隐藏项，管理视图可找回，重扫不得复活隐藏状态。
- (capability) CAP-2：管理员可以为单个 LocalVersion 生成 LibraryChangePlan，预览精确文件、相对路径、大小、目标隔离位置、影响与阻塞原因，计划创建本身零文件副作用。
- (capability) CAP-3：管理员确认有效计划后可以把该 LocalVersion 的冻结文件移入隔离区；整张聚合 Album 的多个版本不得被一个模糊动作批量隔离。
- (capability) CAP-4：管理员可以按不可变隔离清单将文件恢复到原相对路径；任一路径被占用、Root 政策变化或证据漂移时整体阻塞并给出可操作原因。
- (capability) CAP-5：计划、确认、执行、失败、恢复和取消均可审计、精确幂等并受 revision/requestId 保护；部分文件动作不得伪装为成功。
- (capability) CAP-6：用户可以在唱片详情与独立隔离区查看状态、释放空间、关联版本、时间、执行人、失败原因和恢复入口；MEMBER 只读。
- (constraint) 只有 ADMIN 可以隐藏、计划、确认隔离或恢复；MEMBER 只能读取，匿名不得获得路径、隔离清单、actor 或历史。
- (constraint) 涉及目标文件的活动扫描或未完成投送任务必须阻止执行；已完成设备副本只作为影响提示，不被自动删除或修改。
- (constraint) 计划冻结 Root、LocalVersion、revision、文件相对路径、大小和 SHA-256；执行前重新校验，拒绝符号链接逃逸、根边界逃逸、特殊文件与事实漂移。
- (constraint) 隔离目录位于 Music Root 之外并由 COCEAN 单独管理；隔离清单不可变，M1.3 不自动清理或过期删除隔离文件。
- (constraint) 多文件执行失败必须进入 RECOVERY_REQUIRED 或 FAILED 等诚实状态，保留已移动成员和补偿信息，不回滚历史、不覆盖已有目标。
- (decision) 隔离目标以 LocalVersion 为最小安全单位；隐藏以 LibraryAlbum 为展示单位，二者语义与状态独立。
- (decision) 隔离成功后触发受现有互斥规则保护的增量对账；治理记录继续保留，设备副本和历史投送记录不受影响。
- (note) 状态机、执行前置条件、边界矩阵和恢复语义放入 lifecycle-model.md，避免 SPEC kernel 膨胀。
- (constraint) 永久删除保持关闭；不得提供绕过隔离区的删除入口，也不得以保留期结束为由自动删除。
- (direction) 目录/文件改名、跨托管目录移动、sidecar 写入、嵌入标签写回和播放器副本删除不属于 M1.3。
- (direction) 真实 FNOS 只允许在用户另行授权后，以独立 MANAGED QA Root 演练隔离与恢复；不得在现有 Music 主库上首测。
- (assumption) M1.3 隔离文件无限期保留，保留期与永久清理策略留待后续单独规格。
- (assumption) M1.3 首版一次计划只覆盖一个 Root 中的一个 LocalVersion；跨 Root 或跨版本批量动作后续再议。
- (event) 本次采用 express 模式；现有产品 Brief、架构合同和 M1.2 规格足以形成无开放阻塞项的合同。
- (event) Self-Validate Pass 1（Coherence）通过：6 个能力均含 intent/success，ID 唯一；约束、Non-goals、成功信号与假设完整且使用精简用户语言。
- (event) Self-Validate Pass 2（Preservation）通过：用户的管理优先、删除/修改诉求、Brief 的 WATCH_ONLY/MANAGED 与隔离恢复边界、架构的计划/审计要求、M1.2c/d 的非回归边界均进入 SPEC 或 lifecycle-model.md。
- (note) Wrapper-only content：BMAD 流程提示和阶段性执行话术不属于产品合同，未写入 SPEC。
- (event) M1.3 SPEC 已完成并可供 Build 消费；无阻塞性 Open Questions。
